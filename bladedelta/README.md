# BladeDelta — evidence-bounded 3D damage estimation on turbine blades

Research project page (CVPR 2027 target).

- `index.html` — project overview: idea, data, method, results, survey and gaps, plan, full timeline
- `demo.html` — working model: replays the estimator's saved outputs on benchmark cases (3D viewer)
- `slides.html` — research meeting slides (press P to present, N for speaker notes)
- `proposal.html` — research proposal

Data credits: PLAID Rotor37 geometry (CC BY-SA 4.0); BladeSynth (Scientific Data, 2025);
SiM3D (Costanzino et al., ICCV 2025, CC BY-NC-SA 4.0) — real-object image shown for non-commercial research;
AEBIS and RAD example images from the respective public datasets.
