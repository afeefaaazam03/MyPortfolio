What the short presentation is based on

Main Jet · Updated 23 September 2026 · Public presentation evidence note

This page separates measured synthetic results, existing real-image components and future research. It adds no training or inference. The presentation replays actual saved outputs and uses clearly labelled workflow diagrams.

The known damaged 3D shape is a training/evaluation answer, not an input to current prediction. The current system does not reconstruct an unknown complete blade from an arbitrary photograph. Exploratory real-photo surfaces elsewhere on the website have unverified depth.

Data inventory and its limits

  • Current controlled geometry: public Rotor37 blade instances from Safran / PLAID. Three training instances provide 12 states (3 healthy, 9 dents). A separate calibration instance provides 2 states. The latest check used 2 further instances with 18 dents and 2 healthy states.
  • Latest rendered batch: 147 images = 20 states × 7 views + 7 batch-control images. Repeated views and dents are correlated; these are not 147 independent blades. The two latest instances belong to the same public parametric family. They were new at that evaluation and are now exposed.
  • BladeSynth: 12,344 accepted static images: 2,500 healthy and 9,844 anomalous. This appearance library is not a verified collection of 12,344 matching RGB/3D examples.
  • AEBIS: 528 local source-Train image/mask pairs, all damage-positive; 397 used for training and 131 repeatedly used for development. The latter are not an untouched test set.
  • Supplied photos: 174 unique photograph keys, duplicated across two archive formats. Original annotations outline the blade airfoil, not defects. Damage review is separate and partial. This update publishes no additional owner photographs.

Local inventory records: AEBIS_REAL_LOCALIZATION_RESULTS.md, BLADESYNTH_E0_AUDIT.md, USER_REAL_BLADE_EXPERIMENT.md, BLADE_REAL_3D_READINESS.md. Counts describe available material, not a combined independent test population.

What “passed every check” means: fewer false changed points than the original XYZ model, with no worse local or whole-shape RMS error (absolute allowance 10⁻¹²), missed damage support, or flagged face problems in that case. False movement uses a 10⁻⁵ threshold in normalized source units. A pass is a comparison against this baseline, not a declaration that the damage is correctly recovered.

Both methods lowered local and whole-shape error in all 18 normal-input dent cases. However, missed support increased in 15/18 cases for the learned constraint and 14/18 for the fixed projection. The fixed rule had lower whole-shape error and fewer false changes than the new learner in all 18. Small improvements against a weak baseline do not establish accurate reconstruction.

One-pixel reference shifts still produced many false changes, including on healthy examples. Fixed translation alignment is a separate rule-based control. Healthy identical-pair zero output is built into the residual input design; it does not establish real-world specificity. Face flags are limited diagnostics, not physical safety certification.

Implemented, fixed, simulated and planned

  • Learned: the original XYZ movement predictor, the normal-displacement predictor and the separate existing real-image detector.
  • Fixed rules: image-to-surface aggregation, normal projection, domain constraints, image translation alignment and evaluation thresholds.
  • Supplied / simulated: healthy CAD, cameras, correspondence, artificial dents and rendered inspection images in the controlled 3D study.
  • Planned: better spatial support of predicted damage, fresh evaluations, measured real geometry, and a fair comparison of image-only versus geometry-assisted training on independently reviewed real photographs.

No new research experiment ran for this presentation update. No current synthetic result proves a real-photo benefit from the broader proposal.
