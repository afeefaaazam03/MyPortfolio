# Jet Blade 3D presentation redesign

Requested reference: https://afeefaaazam03.github.io/MyPortfolio/main-jet/

The reference page was fetched and inspected on 23 September 2026. Its research-story structure is the important change: a split visual hero, numbered chapters on light backgrounds, data and method figures, a short presentation, implemented examples, and a distinct research proposal. The initial Jet Blade 3D page overemphasized the latest fitting experiment.

## Build

1. A visual project overview: blade images and supplied healthy geometry → a location on the 3D surface and an estimated changed mesh.
2. A six-slide visual explanation, with next/previous controls and keyboard support.
3. A public-data chapter showing source mesh, synthetic inspection images and known evaluation answer.
4. A plain-language input/output workflow and the difference between locating a point and estimating a shape.
5. A completed-work timeline distinguishing earlier learned image localization, earlier learned displacement models, and the latest nonlearned diagnostic comparison.
6. The existing working 68-case viewer, embedded as one current experiment within that wider story.
7. The complete latest findings, then a concise research plan and clearly illustrated future output.

## Reuse

Keep the already exported public Rotor37 assets, exact saved fields, full meshes, complete tables and actual interactive viewer. Create hero before/after stills by rendering those same saved coordinates with the same camera and scale. The slider and future report are presentation components, not new scientific results. Link older public evidence as separately labeled earlier studies. No confidential photos, source-machine paths or fabricated learned predictions will be added.
